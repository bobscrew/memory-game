# Memory Game

Классическая игра на поиск пар, написанная на чистом JavaScript без сторонних библиотек и фреймворков.

## Описание

Игрок открывает карточки по две и пытается найти все совпадающие пары за минимальное число ходов. На поле 16 карточек — 8 пар с одинаковым цветом. Каждая новая игра перемешивает карточки случайным образом.

В игре реализовано:

- автоматический старт при загрузке страницы;
- перемешивание карточек алгоритмом Фишера–Йетса;
- подсчёт ходов и найденных пар;
- задержка закрытия несовпавшей пары с блокировкой кликов;
- три цветовых режима: «Радуга», «Розовый», «Океан»;
- модальное окно победы с итоговым числом ходов;
- таблица лидеров на 10 лучших результатов с сохранением в `localStorage`;
- перезапуск игры без перезагрузки страницы.

Вся разметка создаётся через `document.createElement`. В исходном `index.html` внутри `<body>` находится только тег `<script>`.

### Классы в `game.js`

- `Card` — модель карточки (id пары и цвет).
- `CardGenerator` — статическая фабрика: создание карточек, пар, перемешивание, генерация цвета по HSL.
- `Game` — правила игры и состояние: какие карточки открыты, счётчики, блокировки.
- `GameView` — отрисовка поля и управление DOM-элементами карточек.
- `Modal` — переиспользуемый компонент модального окна.
- `Leaderboard` — работа с `localStorage`: загрузка, сохранение, сортировка результатов.
- `App` — координатор: строит каркас страницы и связывает все части.

## Локальный запуск

Никаких сборщиков и зависимостей не требуется.
Скачайте репозиторий и откройте `index.html` в браузере двойным кликом.

## Как играть

 - Кликните по карточке, чтобы открыть её.
 - Кликните по второй карточке.
 - Если цвета совпали — пара остаётся открытой.
 - Если не совпали — карточки закроются через секунду.
 - Найдите все 8 пар, чтобы победить.
 - Число ходов подсчитывается автоматически. Постарайтесь найти все пары за минимальное количество ходов — результат попадёт в таблицу лидеров.

##  Управление

 - Новая игра — начать заново, карточки перемешиваются, счётчики обнуляются.
 - Таблица лидеров — показать 10 лучших результатов.
 - Селект режима — переключить цветовую палитру, при этом начинается новая игра.
 - Escape или клик по фону — закрыть модальное окно.
